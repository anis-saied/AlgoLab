# AlgoLab

AlgoLab est un repository pour **étudier, expérimenter et améliorer des algorithmes** issus de livres et ressources en algorithmique. Les algorithmes sont implémentés en **Java, C, Python**, et parfois dans d’autres langages selon le besoin. Ce projet sert à la fois de laboratoire pédagogique et de référence pour les tests et optimisations d’algorithmes.

## Fonctionnalités principales

- Implémentations d’algorithmes classiques :
  - Tri : bubble, insertion, quicksort, mergesort, heapsort
  - Graphes : Dijkstra, Bellman-Ford, BFS, DFS
  - Structures de données : listes, piles, files, arbres, graphes
  - Programmation dynamique : knapsack, sous-suite, chemins minimaux
- Tests multi-langage :
  - Java, C, Python
  - Possibilité d’évaluer performances et complexité
- Améliorations et optimisations d’algorithmes existants
- Documentation et exemples pour chaque algorithme

## Installation

**Cloner le repository :**

```bash
git clone https://github.com/votre-utilisateur/AlgoLab.git
```

**Pour Java :**

- Importer le projet dans Eclipse/IntelliJ ou compiler avec :

```bash
javac path/to/*.java
java MainClass
```

**Pour C :**

Compiler avec `gcc` :

```bash
gcc algorithm.c -o algorithm
./algorithm
```

**Pour Python :**

```bash
python algorithm.py
```

## Organisation

- `/java/` → Algorithmes en Java
- `/c/` → Algorithmes en C
- `/python/` → Algorithmes en Python
- `/docs/` → Notes, références et explications théoriques
