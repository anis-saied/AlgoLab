# wget
- Wget stands for "World Wide Web Get" (often shortened simply to "Web Get"). 
    - W: World Wide Web
    - get: The action of retrieving data (referencing the standard HTTP GET request method)
- GNU Wget is a free command-line utility from the GNU Project that retrieves files from web and FTP servers.
- Installation on Linux: `sudo apt-get install wget`
