Angular
is a framwork for building a client applications in html/css, js/typescript(compiled to js)

tutorial url : https://www.youtube.com/watch?v=k5E2AVpwsko


applications = front-end & back-end
front-end : client , runs in a web browser
=> to build the front-end you use : html/css, js/typescript, angular

back-end : is a web server or multiple web servers in the cloud
	responsible of storing the data 
	
the front-end : 
	save/get data from the server
	is all about the presentation : we have
		HTML templates
		Presentation logic
		
	
the server : propose a bunch of http services or API to make this data available to the client
API : application programming interface

-------------------------------
==> HTTP Services / APIs:
End points that are accessible via HTTP protocol
-------------------------------
the front-end : uses simple HTTP request to get or to save the data


At the back-end:
we have one or more data bases
and APIs that make the data available to the clients
and the implementation of the business logic of the application

this app : is building a client apps with Angular

fullstack developper : knows all the front-end and the back-end

!!!! Lets focus on one thing(front-end) and do it well

First Angular App:
how to set the development environment
create your first Angular project

1.
install the latest (have more features) version of node
nodejs.org
nodejs : is a runtime environment to execute a js code outside the browser
node provide some tools (node package manager, ...) that we need to build angular projects
in cmd
>>> node --version
note : minimal version required to build angular app is 6.9

node package manager (NPM): to install third-party libraries

2. 
install the library : Angular CLI 
Angular CLI : stands for (signifie) command-line interface
=> this command-line tool that we use to 
	create a new Angular project 
	or generate some boilerplate code
	or to create deployable packages
	
==>
>>> npm install -g @angular/cli	

NOTE:  npm install -g @angular/cli@latest ==> the last version

-g => to use angular anywhere

to ensure that the installation was successful
>>> ng --version

To update to last version of angular:

>>> ng update @angular/cli @angular/core

source : https://angular.io/guide/setup-local

https://registry.npmjs.org/@angular/cli/8.0.0
