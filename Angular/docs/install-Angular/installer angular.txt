installer les outils et créer le projet:
-----------------------------------------
etape 1: install nodejs
------------------------
node js = runtime pour Javascript (version LTS : long time support : la version stable la plus recente), 


-------------------------------------------------------------------------------
etape 2: install npm
------------------------
npm = node package manager : permet d'installer d'autres packages

pour vérifier que je possède la dernière version de npm:
>>> npm install -g npm@latest

-------------------------------------------------------------------------------
etape 2: install CLI
------------------------
CLI = command line interface: 
outil permet d'executer des scripts depuis la ligne de commande pour
création , structuration et la production de l'application angular

>>> npm install -g @angular/cli

=> le CLI est installé sur votre machine et prêt à être utilisé pour créer votre application

-------------------------------------------------------------------------------
Pour plus d’informations, vous pourrez trouver la documentation de chaque élément sur le site correspondant :

node.js : https://nodejs.org/en/docs/

npm : https://docs.npmjs.com/

ng : https://cli.angular.io/
