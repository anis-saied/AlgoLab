créer des propriétés personnalisées dans un component:
-------------------------------------------------------

il faut utiliser le décorateur  @Input()
N'oubliez pas d'importer  Input  depuis  @angular/core  en haut du fichier !


import { Component, Input, OnInit } from '@angular/core';

  
@Input() appareilName: string;

utilisation simple (valeurs constantes):
----------------------------------------
Ce décorateur, en effet, crée une propriété  : appareilName  
qu'on peut fixer depuis la balise  <app-appareil>
ex:
<app-appareil appareilName="Machine à laver"></app-appareil>


utilisation avancée:
--------------------
Maintenant, utilisez les crochets  []  
pour lier le contenu de ces variables à la propriété du component :

appareilOne = 'Machine à laver';

<app-appareil [appareilName]="appareilOne"></app-appareil>


Remarque:
----------
si vous employez les crochets pour le property binding 
et que vous souhaitez y passer un string directement, 
=>il faut le mettre entre apostrophes, 
car entre les guillemets, il doit y avoir un statement de TypeScript valable. 

<app-appareil [appareilName]="'ordinateur'"></app-appareil>


Attention:
----------
Si vous omettez les apostrophes, 
vous essayez d'y passer une variable nommée  ordinateur  
et l'application ne compilera pas.
